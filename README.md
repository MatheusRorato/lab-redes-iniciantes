# Laboratório de Redes para Iniciantes (Cisco Packet Tracer)

Laboratório prático feito no Cisco Packet Tracer para praticar endereçamento IP e roteamento estático.

## O que foi montado
- Topologia com 4 roteadores Cisco 2911 ligados em anel
- 2 computadores
- Endereços IP atribuídos às interfaces dos roteadores e às máquinas

## O que foi configurado
- Rotas estáticas configuradas manualmente, para que um PC se comunicasse com o outro pelo caminho definido
- Conectividade validada com ping entre os dois computadores

## Conceitos praticados
Endereçamento IP, roteamento estático e teste de conectividade (ping).
